# موقع كابتن محمد صادق (Landing Page)

React + Vite + Tailwind CSS v4 + Swiper. عربي فقط (RTL). مفيش تسجيل دخول ولا لوحة تحكم ولا قاعدة بيانات في المرحلة دي.

## التشغيل

محتاج Node.js إصدار **20.19 أو أحدث** (أو 22.12+).

```bash
npm install
npm run dev       # تشغيل للتطوير
npm run build     # بناء النسخة النهائية في فولدر dist
npm run preview   # تجربة النسخة المبنية
```

لو هترفعه على Vercel: ملف `vercel.json` جاهز. لو Netlify: ملف `public/_redirects` جاهز.

## إزاي تعدّل المحتوى (من غير ما تلمس المكونات)

كل الكلام والصور في فولدر `src/data`:

| الملف | فيه إيه |
|---|---|
| `site.js` | الاسم، أرقام التواصل، السوشيال، روابط القائمة |
| `about.js` | نبذة الكابتن + المؤهل والمسيرة |
| `services.js` | الخدمات الأربعة |
| `method.js` | خطوات طريقة التدريب ⚠️ تجريبي |
| `faqs.js` | الأسئلة الشائعة ⚠️ تجريبي |
| `gallery.js` | صور المعرض (مجموعتين) |
| `videos.js` | الفيديوهات |
| `certificates.js` | الشهادات |

**إضافة فيديو:** حط الملف في `public/videos` والبوستر في `public/posters` وزوّد سطر في `videos.js`.
**إضافة صورة للمعرض:** حطها في `public/images/photos` بنسختين (480 وعرض أكبر) وزوّد سطر في `gallery.js`. (اسم الملف: `اسم-480.webp` و`اسم-960.webp`).
**قسم فاضي؟** لو أي قائمة بقت `[]` القسم بيعرض رسالة "لسه مفيش ..." لوحده.
**السلايدر (Swiper):** بيشتغل بس لو عدد الكروت أكتر من العدد الظاهر على الشاشة. لو أقل، بيتعرضوا كشبكة عادية. الأعداد في `PER_VIEW` جوه كل قسم.

## الألوان والوضع الداكن

الألوان في أول ملف `src/index.css` (فاتح في `:root` وداكن في `.dark`). الوضع بيتحدد حسب جهاز الزائر وزرار التبديل بيحفظ اختياره.

## تجهيز المشروع للمستقبل (مش مطبّق دلوقتي)

- المكونات بتاخد بياناتها من `src/services/content.js` مش مباشرة من `data`. لما نربط Supabase هنغيّر جوّه الدوال دي بس.
- المسارات في `src/routes/AppRoutes.jsx`، والشكل العام في `PublicLayout`. لوحة التحكم لو اتضافت هتبقى ليها Layout ومسارات منفصلة.
- فورم الحجز بيفتح واتساب برسالة جاهزة، ومبيحفظش حاجة ومبيأكدش حجز.
